# 番茄小憩 PomoRest

一个常驻 Windows 桌面的番茄钟 + 护眼提醒组件：默认窗口置顶、可拖动、可折叠到托盘。

## 功能

- **番茄钟**：专注 / 短休 / 长休循环，每 4 轮长休，自动开始休息 / 下一轮可配置。
- **护眼提醒（20-20-20）**：每 20 分钟提醒远眺 20 秒，可全屏遮罩，可严格模式（不可跳过）。
- **备注**：每个番茄专注尝试可写一条备注（最多 200 字），随历史保存并导出。
- **历史记录**：按天保存专注记录、备注、护眼次数，应用内可查看，可导出明细 / 每日汇总 CSV。
- **背景音乐**：可配置 1–6 个网页链接，番茄专注开始（含继续）时按需打开。
- **开机自启动**：默认开启，首次启动写入当前用户启动项。
- **窗口置顶**：默认开启，点击标题栏右上角图钉即可切换；隐藏到托盘后不显示。

## 使用

1. 双击 `Start PomoRest.cmd` 或 `dist\PomoRest.exe`。
2. 主卡片默认出现在屏幕右上角；点击「开始」启动当前模式。
3. 顶部按钮：图钉（窗口置顶开关）、紧凑模式、设置、隐藏到托盘。
4. 底部「今日统计」或托盘「查看记录」打开历史记录。
5. 托盘图标左键显示/隐藏，右键打开完整菜单，含「退出」。
6. 窗口默认显示在任务栏；点击「隐藏」后从任务栏消失，可用托盘图标恢复。

快捷键（主窗口聚焦时）：

- `空格` 开始 / 暂停
- `R` 重置
- `S` 跳过（护眼模式下为「现在休息」）
- `1` 番茄钟
- `2` 护眼提醒
- `Esc` 隐藏到托盘

## 数据位置

- 设置 / 窗口位置 / 当前会话：`%APPDATA%\PomoRest\state.json`
- 历史记录：`%APPDATA%\PomoRest\history.json`（自动保留 `.bak` 备份）
- 错误日志：`%APPDATA%\PomoRest\error.log`

所有数据仅保存在本机，应用不联网、不采集任何信息。

## 导出

在「历史记录」页点击「导出明细 CSV」或「导出汇总 CSV」：

- 明细 CSV：日期、开始/结束时间、计划/实际时长、状态、备注。
- 汇总 CSV：日期、完成番茄数、专注分钟、护眼次数、备注数。

文件使用 UTF-8 BOM，Excel 双击即可打开，中文不乱码。

## 背景音乐说明

- 设置页「背景音乐」可添加最多 6 个 `http/https` 链接，每条可命名、启用、测试。
- 只在番茄专注开始（含继续）时触发，不在短休、长休、护眼休息时打开。
- 应用只判断「由它自己打开的音乐浏览器窗口是否仍存在」，窗口被关闭后下一次专注开始会自动重新打开。

**明确限制**：普通 Windows 应用无法通用、可靠地读取浏览器标签页。应用不会读取或操纵浏览器标签页；若你已在其他窗口手动打开同一页面，应用可能再开一个窗口。多个链接会作为同一个新浏览器窗口的标签页打开。浏览器可能因策略阻止自动播放，应用只负责打开页面。

## 开机自启动与卸载

- 自启动默认开启；在设置页「开机自启动」开关关闭即可删除启动项。
- 移动 exe 后，下次手动启动会自动更新启动路径。

卸载：退出应用 → 删除 `dist` 目录 → 删除 `%APPDATA%\PomoRest` → 如需清理启动项，删除注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 中的 `PomoRest`。

## 从源码构建

环境：Windows 10/11 x64，系统自带 .NET Framework 4.8，无需 Node / NuGet / 联网。

```powershell
.\build.ps1   # 运行单元测试并编译 dist\PomoRest.exe
.\test.ps1    # 仅运行单元测试
```

构建产物为单文件绿色版 `dist\PomoRest.exe`。

## 关于「未知开发者」提示

应用未进行代码签名，Windows SmartScreen 可能在首次运行时提示「Windows 已保护你的电脑」或「未知发布者」。说明：

- 这不是病毒，是 Windows 对「未签名、无下载信誉」程序的通用提示。
- 点击「更多信息 → 仍要运行」即可继续，之后通常不再提示。
- 若文件是从网上下载/解压得到，`Start PomoRest.cmd` 会自动执行 `Unblock-File` 清除「来自 Internet」标记；也可手动在文件「属性」中勾选「解除锁定」。
- 要**彻底消除**该提示，需要用受信任的代码签名证书（付费 EV/OV 证书）对 exe 签名；普通自签名证书无法消除 SmartScreen 提示。若你提供证书，可在构建脚本中加入签名步骤。

## 已知限制

- 仅中文界面、深色主题。
- 窗口置顶开启时仍无法覆盖独占全屏应用（系统限制）。
- 护眼遮罩覆盖组件所在显示器（多屏用户请在主屏使用）。
- 应用未签名，首次运行可能出现 SmartScreen 提示（见上）。
